# Milestone v18.1: UI & Localization Consistency Polish

**Status:** Active  
**Milestone Goal:** Eliminate remaining hardcoded strings, dropdown inconsistencies, and edge-case bilingual text across Document Move/Copy modals, House Profile tabs, navbar stats, and management dialogs, ensuring 100% pure language rendering in both Arabic and English modes.

---

## Phases

### Phase 125: Move & Copy Modals Folder & Options Localization

- **Goal:** Localize standard folder names, optgroups, action triggers, and subtitles inside Move and Copy document modals (batch and single-document).
- **Requirements:** `MOVE-01`, `MOVE-02`, `MOVE-03`
- **Success Criteria:**
  1. Standard category folders in batch and single Move/Copy modals render localized labels according to the active language (e.g. `05 - Contracts` in English vs `05 - عقود` in Arabic).
  2. Optgroups (`Standard Folders`, `Custom Folders`), action options (`+ Create New Folder...`), and modal subtitles render purely in the active language.
  3. Document move and copy execution works seamlessly with existing backend endpoints and DOM updates.

### Phase 126: House Profile Tabs & Router Navigation Dynamic Localization

- **Goal:** Dynamically localize segmented navigation tabs in house and tenant views, subscribe router to language change events, and eliminate side-by-side language mixing.
- **Requirements:** `TAB-01`, `TAB-02`, `TAB-03`
- **Success Criteria:**
  1. In house view, the first tab displays pure localized text (`Tenants` / `سجل المستأجرين`) and the timeline tab displays pure localized text (`House Timeline` / `التسلسل الزمني للمنزل`).
  2. In tenant view, the first tab displays pure localized text (`Folders` / `المجلدات`) and the timeline tab displays pure localized text (`Tenant Timeline` / `التسلسل الزمني للمستأجر`).
  3. Router subscribes to `languageChanged` event so tab labels and header breadcrumbs update instantly upon language toggle without a page reload.

### Phase 127: Tenant Suffixes, Header Stats & Management Modals Clean-Up

- **Goal:** Localize tenant status suffixes, top navbar stats badge, Manage Tenants modal tooltips/placeholders, and single doc action modal buttons.
- **Requirements:** `TSEL-01`, `TSEL-02`, `EDGE-01`, `EDGE-02`
- **Success Criteria:**
  1. Move & Copy tenant dropdowns format the current tenant suffix in the active language (` (Current Tenant)` in English vs ` (المستأجر الحالي)` in Arabic).
  2. Top navbar house stats badge formats counts and labels purely in the active language (`N Tenants • M Documents` vs `N مستأجرين • M وثائق`).
  3. Manage Tenants dialog tooltips/placeholders and single doc action modal mode buttons eliminate hardcoded text and bilingual bullet separators (` • `).

### Phase 128: Automated Localization Suite & Full Regression Verification

- **Goal:** Add comprehensive automated unit/component tests for new localization features and verify 100% test pass rate across the full test suite with zero regressions.
- **Requirements:** `TEST-01`, `TEST-02`
- **Success Criteria:**
  1. Automated tests verify Move/Copy modal folder translations, tab label updates, tenant suffix localization, and stats badge formatting across Arabic and English.
  2. All 49+ test files and 704+ tests pass 100% with zero failures.
  3. 100% static asset parity between `src/HousingApplication.Web/wwwroot/` and `dist/win-x64/wwwroot/` is verified.
