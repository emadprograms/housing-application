## 3. Cross-Phase Integration & End-to-End User Flows

1. **Initial Page Load:**
   - Pre-hydration language detection reads `localStorage.getItem('app_language')` or defaults cleanly to Arabic (`ar`).
   - Root document attributes initialized: `lang="ar"`, `dir="rtl"`.
   - UI elements decorated with `data-i18n` resolve immediately to clean Arabic without bilingual artifacts.
2. **Dynamic Language Switch Flow:**
   - User clicks `#lang-toggle-btn`.
   - `window.i18n.setLanguage('en')` persists `'en'` to `localStorage`.
   - `dir` flips to `'ltr'`, `lang` flips to `'en'`, CSS mirroring adjusts flex direction and chevron arrows.
   - `languageChanged` event dispatches and updates all active modules (`area-grid`, `house-profile`, `categories-view`, `timeline-view`, `doc-viewer`, `doc-manager`, `doc-page-editor`, `tenant-manager`, `auth-manager`).
   - All interactive controls, tooltips (`data-i18n-title`), placeholders (`data-i18n-placeholder`), and accessibility labels (`data-i18n-aria`) render cleanly in English.
3. **Session Persistence Flow:**
   - User reloads or re-navigates.
   - Application boots directly in English mode without flash of Arabic content.
4. **Dialogs & Workflows in Both Languages:**
   - Document Viewer, Page Editor (split/delete/extract/rotate), Merge modal, and Ingestion Station operate with 100% single-language labels and feedback toasts.
   - Zero bilingual intermixed strings (`Word • كلمة`, `Word / كلمة`, dual subtitles) remain.
