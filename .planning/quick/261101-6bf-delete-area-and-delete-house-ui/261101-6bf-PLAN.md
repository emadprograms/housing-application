# Quick Task: 261101-6bf-delete-area-and-delete-house-ui
# Add Delete Area Endpoint & Modal + Discoverable Delete House Entry Points

## Objective
Implement full Admin-only **Delete Area** support (`DELETE /api/areas/{areaId}` + typed confirmation modal + sidebar & Area Overview header triggers) and surface **Delete House** directly on Area Grid house cards and in the House panel header so Admins do not have to dig into the House Settings modal's Danger Zone.

## Context & Key Rules
1. **Transactional Cascade & Disk Safety (`DeleteAreaAsync`)**:
   - Deleting an area transactionally removes all child `pages`, `documents`, `batches`, `tenants`, and `houses` belonging to that area before executing `DELETE FROM areas WHERE id = @AreaId`.
   - Recursively removes `<AreasRoot>/<areaId>` on disk only after verifying strict path containment inside `AreasRoot`.
2. **RBAC Enforcement**:
   - Both `DELETE /api/areas/{areaId}` and all delete UI triggers (`.area-delete-btn`, `#btn-delete-area-header`, `.house-card-delete-btn`, `#btn-delete-house-quick`) are restricted strictly to **Admin** accounts (`hasDeletePermission()` / `!IsRestrictedFromDelete`). Contributor accounts receive `403 Forbidden` on the API and never see delete triggers in the UI.
3. **Destructive Action Guard**:
   - Both `#delete-area-modal` and `#delete-house-modal` require typing `delete <name>` (case-insensitive) before enabling the permanent delete button.
4. **Clean Bilingual Localization & Asset Parity**:
   - All new labels/titles use clean single-language Arabic (`ar`) and English (`en`) entries in `i18n.js` with zero mixed `" / "` or `" • "` pairs, dark-mode selector parity in `styles.css`, and 100% mirror parity in `dist/win-x64/wwwroot/`.

## Tasks

   - Map `DELETE /api/areas/{areaId}` in `Program.cs` with `IsRestrictedFromDelete` (`403`), `400`, `404`, and `200` responses.
   - Add xUnit test `DeleteArea_DeletesAreaHousesDocumentsAndDirectory_AndEnforcesAdminRbac` in `ApiEndpointTests.cs`.

   - Add `#delete-area-modal`, `#btn-delete-area-header`, and `#btn-delete-house-quick` to `index.html`.
