# Archived Python Utilities (`scripts/legacy/`)

This folder preserves historical Python v5–v11 batch-ingestion, migration, verification, and API-key utility scripts along with legacy YAML/env configuration templates (`scripts/legacy/config/`).

Since Milestone v15.0, the runtime application is 100% ASP.NET Core + SQLite (`src/HousingApplication.Web/` and `dist/win-x64/FileOrganizer.Web.exe`) with zero Python runtime dependency. Active operational scripts live in the parent `scripts/` and `scripts/service/` directories.
